# CareerConnect

CareerConnect is a Django-based job portal that connects students/job seekers with recruiters.

## 🚀 Live Demo

https://careerconnect-mtl1.onrender.com

## ✨ Features

### 👨‍🎓 Student
- User registration and login
- Browse available jobs
- Search and filter jobs
- Apply for jobs
- Track applications
- Withdraw applications
- Save jobs
- View notifications
- Manage profile

### 🧑‍💼 Recruiter
- Recruiter dashboard
- Create and manage jobs
- Edit and delete jobs
- Close and reopen jobs
- View applicants
- Update application status
- Manage posted jobs

## 🛠️ Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap
- JavaScript
- Git & GitHub
- Render

## 🗄️ Database

The production application uses PostgreSQL.
